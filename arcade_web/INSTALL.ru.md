# Установка визуальных игр (Telegram Mini App)

Игры: змейка, кристалики, слоты, марио, покер, танчики (99 уровней). Папка с кодом: `app/telegram/arcade_web`.

**Обновление на телефоне:** после заливки на GitHub Pages увеличьте `window.ARCADE_BUILD` и `?v=…` в `index.html` (сейчас `20260529-4`), загрузите также `maps/levels.json` и `tanks.js`. Иначе Telegram может показывать старую версию из кэша.

---

## Вариант 1: Опубликовать на хостинге

Разверните содержимое папки `arcade_web` по **HTTPS**:

| Сервис | Примечание |
|--------|------------|
| [GitHub Pages](https://pages.github.com/) | Папка `docs/` или ветка `gh-pages` |
| [Netlify](https://www.netlify.com/) | Перетащите папку в интерфейс |
| Cloudflare Pages, Vercel | Аналогично — статический сайт |

URL должен открывать `index.html`, например:

```text
https://your-login.github.io/aura-games/
```

### В программе Aura

1. Вкладка **Telegram** → блок **«Визуальные игры (Telegram Mini App)»**.
2. Вставьте HTTPS-адрес в поле **URL Mini App**.
3. Нажмите **«Сохранить URL»** — если бот уже был запущен, Aura **перезапустит его автоматически**.
4. В Telegram: **«🎮 Игры за очки»** → **«🕹 Визуальные игры»**.

Альтернатива: вручную в `C:\Users\<вы>\.aura_numerology\config.json`:

```json
"arcade_web_url": "https://your-login.github.io/aura-games/"
```

После правки файла перезапустите бота в Aura.

## Вариант 2: Локальное тестирование (без постоянного хостинга)

Telegram принимает только **HTTPS**. Локальный `http://127.0.0.1` в боте не работает — нужен туннель (ngrok и т.п.).

### Шаг 1 — локальный сервер

В Aura нажмите **«Локальный сервер (8765)»** или в терминале из корня проекта:

```bash
python scripts/serve_arcade_web.py
```

Проверка в браузере: http://127.0.0.1:8765/

### Шаг 2 — публичный HTTPS

В **другом** терминале:

```bash
ngrok http 8765
```

Скопируйте адрес вида `https://xxxx.ngrok-free.app/` (обязательно **https**).

### Шаг 3 — Aura

1. Вставьте этот HTTPS-URL в поле **URL Mini App**.
2. **«Сохранить URL»** → перезапуск бота (если был запущен).
3. Проверьте кнопку **«🕹 Визуальные игры»** в боте.

## Скрипт `scripts/serve_arcade_web.py`

Запускает статику игр на порту **8765** для проверки перед выкладкой на хостинг.

```bash
python scripts/serve_arcade_web.py
python scripts/serve_arcade_web.py --port 9000
```

## Как это работает для пользователя

1. Игра открывается полноэкранно внутри Telegram.
2. По окончании — **«Отправить результат в бот»**.
3. Бот начисляет очки ауры (те же лимиты партий в сутки, что у кнопочных игр).
4. Игры с картинкой поля в чате (казино, змейка и т.д.) работают **без** Mini App — отдельно.

## Частые проблемы

| Проблема | Решение |
|----------|---------|
| Нет кнопки «Визуальные игры» | URL пустой или не начинается с `https://` |
| Mini App не открывается | Проверьте URL в браузере; для ngrok — бесплатный лимит/регион |
| Очки не начислились | Нажмите «Отправить результат в бот»; проверьте лимит партий в сутки |
