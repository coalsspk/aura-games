# Aura Games — Telegram Mini App



Визуальные игры (змейка, кристалики, слоты) в полноэкранном режиме Telegram.



**Подробная установка:** [INSTALL.ru.md](INSTALL.ru.md)



## Быстрый старт (Aura GUI)



1. Опубликуйте эту папку на HTTPS или используйте ngrok (см. INSTALL.ru.md).

2. Aura → вкладка **Telegram** → **URL Mini App** → **Сохранить URL**.

3. Запустите бота → в Telegram: **🎮 Игры за очки** → **🕹 Визуальные игры**.



## Локальный сервер



```bash

python scripts/serve_arcade_web.py

```



Или кнопка **«Локальный сервер (8765)»** в Aura. Для Telegram нужен публичный HTTPS (`ngrok http 8765`).



## Как работает



- Игры в браузере внутри Telegram.

- **«Отправить результат в бот»** → лимиты партий и очки ауры, как у кнопочных игр.

- В чате также доступны игры с картинками поля (без Mini App).
